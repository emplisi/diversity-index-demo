This demo shows diversity by design for the European Health Data Space.

  • Quantify. The Shannon Diversity Index (SDI) scores how evenly people are spread across subgroups, from 0 (one group) to 1 (perfectly even). A Composite SDI gives one score per domain: demographics, socioeconomic, geography, clinical and genetic.
  • Standardize. Each dataset's HealthDCAT-AP record carries its Composite SDI and missingness as DQV quality measurements. Subgroup detail sits in a linked HL7 FHIR MeasureReport.
  • Collaborate. Whether a dataset is diverse enough depends on the research question. Open a dataset, choose the populations (e.g. age group × sex) and filter the records (e.g. statin users) to compute a custom diversity index.
  • Privacy. Computations can be more private using differential privacy.

All datasets are synthetic.

Composite Diversity Index by Domain
Mean normalised H̃ (H / ln K, K = size of the shared code list) across the axes of each domain, as published in the HealthDCAT-AP record.
Select which axes define your populations, optionally filter records and add privacy, then click Compute. Shannon H̃ is computed over the joint populations of the selected axes (e.g. age group × sex).
1 · Select populations
Each selected axis defines a set of populations (e.g. age groups, nationalities). With several axes, populations are their combinations.
2 · Filter records (optional) ▼
Unchecking values narrows which records are included. Leaving all checked = full dataset.
3 · Privacy (optional)
Laplace noise with scale 1/ε is added to every population count, including empty ones, before the index is computed. One person changes one count by at most 1. Smaller ε means stronger privacy and a noisier result.
Diversity Results
Shannon indices are computed over non-missing values only, so high missingness can make a dataset look more diverse than it is. Missingness is published next to the Composite SDI in the catalogue record.
